# Descuadres de nómina

## Objetivo

Identificar el origen de diferencias entre los valores esperados y los valores calculados.

## Checklist de diagnóstico

- Confirmar el periodo y empleado afectados.
- Revisar los datos de entrada utilizados para el cálculo.
- Comparar el resultado con el detalle del cálculo.
- Registrar el valor esperado y el valor obtenido.
- Documentar cualquier ajuste realizado.
