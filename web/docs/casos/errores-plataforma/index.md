# Errores de plataforma

## Objetivo

Estandarizar el diagnóstico de errores técnicos.

## Checklist de diagnóstico

- Copiar el mensaje exacto del error.
- Registrar la pantalla o módulo donde aparece.
- Indicar los pasos que provocan el error.
- Comprobar si el incidente ocurre con otros usuarios.
- Registrar fecha, hora y navegador utilizado.

## Solución

Documenta aquí la solución verificada y las condiciones en las que aplica.
