# Acceso de usuarios

## Objetivo

Registrar de forma consistente los casos en los que un usuario no puede acceder.

## Checklist de diagnóstico

- Confirmar el correo electrónico utilizado.
- Confirmar que la cuenta exista y esté habilitada.
- Verificar si el problema corresponde a contraseña, correo no verificado o permisos.
- Registrar el mensaje exacto mostrado por la plataforma.
- Comprobar si el problema se reproduce en otro navegador o dispositivo.
