# Documentación de nómina

Centraliza aquí fórmulas, cálculos y procedimientos utilizados para atender casos relacionados con nómina.

## Estructura recomendada

Para cada cálculo documenta:

- Datos de entrada.
- Fórmula o regla.
- Resultado esperado.
- Ejemplo.
- Validaciones y excepciones.
